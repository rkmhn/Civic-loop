# CivicLoop 🏙️

**CivicLoop** is a civic-tech platform that enables citizens to report local municipal issues, track their resolution in real time, and participate in community budget voting — bringing transparency and accountability to local governance.

## Overview

CivicLoop connects citizens directly with municipal departments through a live, trackable complaint system. Instead of filing a complaint and waiting in the dark, residents can follow their issue from submission to resolution, see which department and squad is assigned, and view verified timelines.

The platform also gives citizens a voice in how public funds are allocated through a participatory budget voting feature.

## Key Features

### 📋 Public Tracker
- Search and track civic complaints by ticket number, ward, or street name
- Filter issues by status: **Received**, **In Progress**, or **Resolved**
- View assigned municipal department (e.g., Public Works Department / PWD) for each ticket
- See exact location details for reported issues (road, landmark, area)

### 🔥 Hotspot Map
- Visualize clusters of civic issues across the city to identify problem areas needing urgent attention

### 🗳️ Voting Box
- Citizens can vote on how allocated civic budgets should be spent within their community

### 📊 Live Dashboard (Nagrik Seva Live / Citizen Service Live)
- Real-time stats including:
  - Active complaints count
  - Number of problem clusters identified
  - Total citizen-approved budget

## Example Use Case

A resident notices a deep pothole near a busy junction. They:
1. File a report through CivicLoop with the location and description
2. Get a ticket number (e.g., `#101`) to track progress
3. See the issue get assigned to the relevant department (e.g., PWD)
4. Watch the status move from **Received** → **In Progress** → **Resolved**
5. Optionally vote on future budget allocation for infrastructure improvements in their ward
